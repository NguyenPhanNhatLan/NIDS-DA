# Archived Funnel experiments

Historical snapshots of the 5D and 16D Funnel experiments, removed from active
`src/`, `configs/` and `docs/`. They are excluded from the canonical proposal_v2 suite.
Original files are retained for reference; their former module commands and relative
paths are historical and do not run directly from this archive.

Existing experiment checkpoints/results remain in their original model/result
directories. SupCon E1/E2 extension code, configs and tests were removed separately;
their completed result artifacts were preserved.

The supported canonical entry point is `python -m experiments.proposal_pipeline`.
