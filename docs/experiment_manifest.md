# Experiment manifest

The single runtime authority is `data/revisions/canonical/manifest.json`.
It is generated by `python -m experiments.proposal_pipeline --stage prepare`.
No static hash inventory or historical output root is treated as a second authority.

The manifest contains the data revision, shared common/prepared roots, source-only
preprocessing parameters, file hashes, audit reports, corrected split membership
policy and counts. Its checksum is stored in `manifest.sha256` beside it.
Every training/evaluation stage verifies this manifest and the frozen files.

The required matrix is 2 directions × 5 seeds × 4 methods, defined in
`configs/proposal_suite_v2.json`. Models and results belong to `models/canonical/`
and `results/canonical/`. A completed manifest certifies data preparation, not
completion of the training matrix or final evaluation.

Run instructions: `README.md`. Data contract: `canonical_data_revision.md`.
